# Prompting Strategies: Zero-Shot, Few-Shot & Structured Reasoning
## Project Objective
This project explores different prompting strategies for Large Language Models (LLMs) and compares their effectiveness in customer statement classification.
## Prompting Techniques
- Zero-Shot Prompting
- Few-Shot Prompting
- Structured Reasoning
## Use Case
The project uses customer statements related to electricity and energy services and classifies them into predefined categories.
## Goal
The goal is to understand how different prompting techniques can influence the accuracy and consistency of LLM responses.
